# UX Factor Identification

## 1. Intuitive Operation

**Definition**

The user is able to handle ESBot without help or further training.

**Relevance for users**

The students do not want to read documentation or watch tutorials in order to use the chatbot.

**Example**

When a student wants to use the chatbot a day before an exam he wants to use it instantly without reading complex documentation.


## 2. Helpfulness / Efficiency

**Definition**

ESBot brings advantage in learning such as increasing the productivity and speed of learning.

**Relevance for users**

Only positive effects in learning (more productivity and increasing speed) make the chatbot useful.

**Example**

When learning for an exam the student wants the content to be stored in long-term memory without investing too much time.


## 3. Ease of use

**Definition**

Using and achieving the wanted goals with ESBot is easy. The usage itself does not require any mental effort.

**Relevance for users**

Students only want to use a chatbot that's not mentally taxing to operate.

**Example**

After learning for many hours the student wants to use the chatbot for learning another topic. He cannot invest mental effort in using the application.


## 4. Correctness

**Definition**

All results provided by ESBot are correct. The results follow the content of the users learning material and trustworthy literature.

**Relevance for users**

Chaotic or incorrect answers make the chatbot pointless or even counterproductive.

**Example**

 A Student uses the chatbot for exam preparation. He trusts the correctness of the answers and learning sessions with the chatbot. The incorrect answers make the student learn wrong information.


## 5. Controllability

**Definition**

ESBot always reacts deterministicly and consistently.

**Relevance for users**

Functions that behave other than expected frustrate the users.

**Example**

If a student learns for an exam and ESBot deletes the chat history when going back to the main page, the student will get angry and loose much time.
